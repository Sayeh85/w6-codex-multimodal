# Image to Text — Ollama Vision

A responsive browser app that previews one or two images and requests a description from a local Ollama vision model.

## Requirements
- Ollama installed and running locally
- One vision model, e.g. `llava` or `llama3.2-vision`
- A local static web server (recommended; avoid opening the HTML as `file://` because browser CORS rules may block Ollama)

## Run
1. In a terminal, download a vision model: `ollama pull llava`
2. Start Ollama: `ollama serve` (if your installation does not already start it automatically).
3. In another terminal, open this project folder and run `python -m http.server 8000`.
4. Open `http://localhost:8000` in your browser.
5. Select one or two images, choose the model you downloaded, then click **Describe image(s)**.

If the browser reports a CORS error, configure Ollama's `OLLAMA_ORIGINS` to allow `http://localhost:8000`, then restart Ollama. Keep the service local and do not expose it to untrusted networks.

## Files
- `index.html` — interface and upload controls
- `style.css` — responsive visual styling
- `main.js` — previews, Ollama requests, results, validation, and error states
- `prompt-history.txt` — iterative prompt-history starter
- `output/` — required screenshots (capture the six real app states here)
